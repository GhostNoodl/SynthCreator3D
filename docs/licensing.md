# Licensing

This project is a customization tool **for** the paid
[Synth VRChat model by Zairiza](https://zairizacustoms.itch.io/synth-vrchat-model).
The model's files (Blender/FBX/OBJ/PSD/unitypackage and anything derived from them,
including converted GLB/texture packs in `assets/`) are **not** part of this
repository and must never be committed — hence the `assets/` ignore rule.

- Each user must own a purchased copy of the model. The app's first-run flow
  converts the user's local files into a model pack on their own machine.
- Redistribution of the model or converted derivatives is prohibited by the
  creator's terms of use unless explicit written permission is obtained.
  (Outreach to Zairiza about bundling permission is tracked as a project task.)
- The Synth *species* is an open species by Vader-San; this restriction is about
  the specific purchased model files only.
